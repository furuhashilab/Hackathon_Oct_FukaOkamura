## 成果物でできること

Panoramax からダウンロードした撮影シーケンス一覧（`collection.csv`）をもとに、写真の撮影地点を地図と表で確認できます。

- **集計**：シーケンス数・写真数・合計距離・撮影期間をページ上部に表示
- **地図**（Leaflet / OpenStreetMap）
  - Panoramax から写真の情報を読み込み、写真 1 枚ごとに撮影地点を点で表示（同じシーケンスの写真は撮影順に線でつなぎます）
  - 点をクリックすると、**写真のサムネイル**・撮影日時と、「高解像度で開く」「Panoramax で見る」へのリンクを表示
  - 写真を取得できなかったシーケンスは、撮影範囲を四角（1 枚だけのものは丸）で表示
- **表**
  - 見出しをクリックすると並べ替え、検索欄で名前・日付・ID による絞り込み
  - 行をクリックすると、地図がその撮影場所へ移動
- **CSV のダウンロード**：元データをページからダウンロード可能

撮影場所は、イタリアのヴェネツィア・フィレンツェ・ミラノと、名古屋です。

### ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開ページ本体。`collection.csv` を読み込んで地図と表を表示し、写真は Panoramax（panoramax.openstreetmap.fr）の API から取得 |
| `collection.csv` | Panoramax からダウンロードした撮影シーケンス一覧（元データ） |
| `.nojekyll` | GitHub Pages で Jekyll による変換をしないための設定 |

`index.html` をファイルとして直接ブラウザで開いた場合も、ページ内に埋め込んだ同じデータで表示されます。`collection.csv` を差し替えたときは、`index.html` 内の埋め込みデータも合わせて更新してください。

## Panoramax とは何か

Panoramax は、誰でも参加できるオープンな「ストリートビュー」プラットフォームです。Google ストリートビューのように、実際の道路や風景を写した写真を地図と連動して閲覧できますが、決定的な違いが 2 つあります。撮影者は市民や自治体など誰でもよく、写真はすべてオープンライセンスで公開されます。

[Panoramax - The free alternative to photo-mapping territories](https://panoramax.fr/)

### 誕生の背景

Panoramax は 2022 年、フランス国立地理院（IGN）とフランスの OpenStreetMap コミュニティが共同で立ち上げました。発端は 2021 年にさかのぼります。IGN が「ジオコモンズ（地理情報の公共財）」をテーマにパートナーを募ったとき、OpenStreetMap France がオープンな路面写真データベースの創設を提案し、採択されたのです。

当初の動機は実用的なものでした。フランスの地方自治体が道路設備の台帳更新や道路インフラの管理に使えるツールが必要とされていました。プロジェクト名「Panoramax」は、48 人のコミュニティメンバーによる提案と投票を経て決まっています。予算は 50 万ユーロ、2024 年 3 月時点のチーム規模は 6 名という、スモールスタートのプロジェクトです。

### 使い始めてびっくり！

フェデレーション（分散）方式を採用していることです！ 個人や組織が独自のインスタンス（サーバー）を運営でき、それらが連携してひとつの大きなネットワークを構成しています。

つまり、写真をアップロードするときに、どこにアップロードするかを選ぶ必要があります。今回、私は OSM-FR（panoramax.openstreetmap.fr）から写真をアップロードしました。

ちなみにアプリもありますが、今回は iPhone の標準カメラで写真を撮り、その写真をブラウザからアップロードしました。

## 使ってみた感想

この一週間イタリアを観光していたので、歩きながらでも簡単にできる Panoramax はよかったです。標準カメラで風景を撮影しておけば、あとからまとめてアップロードすればよいので、旅行中でも手軽に続けられました。

## Claude Code を使用して GitHub を更新した感想

Panoramax に写真をアップロードした後、CSV 形式でダウンロードし、Claude Code に地図を作ってもらいましたが、あっというまにできあがりました。さらに「地図の点を押したら写真が見えるようにできる？」とお願いすると、Panoramax から写真を読み込んで表示する機能も追加してくれました。

GitHub Pages の設定は Claude 自体ではできなかったため、手動で設定する必要がありました。やり方が分からなくても、その状況を説明したり、スクリーンショットを送ったりすると、エラーの原因やその解決方法を提示してくれるので、その方法でお願いすると解決しました。

GitHub の仕組みを理解していなくても作れてしまうのは、とても簡単で便利です。ただ、最後にはそれが合っているかを確認できる知識は必要だと思いました。
